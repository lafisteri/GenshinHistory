# Genshin History

Локальное приложение для сохранения истории экипировки персонажей Genshin Impact по открытой витрине Enka.Network.

## Запуск

Установите Node.js 20.19+ (или 22.12+) и выполните в каталоге проекта:

```bash
npm install
npm run dev
```

Откройте http://localhost:3000, введите UID и нажмите «Обновить витрину». В настройках профиля игры необходимо включить показ характеристик и добавить персонажей в витрину. Запрос выполняется вручную; Enka может возвращать кешированные данные, поэтому повторное обновление доступно после истечения `ttl`.

Для производственной сборки используйте `npm run build`, затем `npm start`. Проверки: `npm test` и `npm run build`.

## Данные

Снимки хранятся в `data/<UID>/<имя персонажа>/<время UTC>.json`, изображения — в `data/images`. Для резервной копии достаточно скопировать каталог `data`. Данные игрока не отправляются никуда, кроме запроса UID к Enka; приложение слушает только localhost. Для просмотра уже сохранённых снимков интернет не требуется. Справочники устанавливаются с приложением, изображения кешируются при получении. Если справочник устарел, неизвестные названия отображаются по ID; обновить его можно обновлением зависимостей и файлов в `reference`.

Состав витрины ограничен тем, что возвращает Enka. Снимок создаётся только при изменении оружия или артефактов; данные персонажа сохраняются в нём для контекста. Ошибка отдельного персонажа не блокирует остальных. Последний повреждённый снимок нужно восстановить или удалить вручную, прежде чем для персонажа можно будет снова сохранять историю.
